# Security

Please don't open a public issue for a security problem.

Email **hello@kons.design** with what you found, how to reproduce it, and what
it lets someone do. You'll get an answer within a week. A fix will be released
as soon as it's ready, and you'll be credited unless you'd rather not be.

What counts: anything that lets someone read numbers they shouldn't, forge or
flood the collector past its limits, recover an address or user agent from
stored rows, or run code on a server through the collector.

Supported versions: the latest release.
