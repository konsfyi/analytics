# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, and keep criticism about the work. No
harassment, insults or personal attacks, in any space the project uses.

Report anything that breaks this to **hello@kons.design**. Reports are read
by the maintainer only and handled in confidence. The maintainer may remove,
edit or reject comments, commits, issues and pull requests that don't follow
it, and may block anyone who repeatedly doesn't.
